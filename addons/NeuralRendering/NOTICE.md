This addon is a new implementation, independent of the retired DLSS5NR01 engine. Its combined source is distributed under GPL-3.0-only; see LICENSE. The manager SDK and other products retain their existing licences. Distribution of this addon must include the GPL notice and corresponding source, including these shaders, build scripts and modifications; a DLL-only bundle is not a complete source distribution.

Original path: `OptiScaler/shaders/dlssnr/precompile/dlssnr.hlsl` in https://github.com/Dagherbou/OptiScaler_DLSSNR . Its RenoDX-derived colour composition is credited in `licenses/RenoDX_ATTRIBUTION.txt`, including the MIT notice.
- NVIDIA Optical Flow D3D12/Common headers: imported unchanged from `third_party/nvof/` in https://github.com/DaniilSokolyuk/video2dlssnr at `9e1bbfa5a700d0cd63b224ab6d95581bfe7ec959`. NVIDIA's MIT copyright/licence remains in each header.
- The D3D12 optical-flow integration was informed by that video's `src/optflow_nvof.cpp`; its MIT notice is retained in `licenses/video2dlssnr-MIT.txt`. This implementation uses bounded command resources, explicit GPU fences, current-to-previous flow, and no production CPU vector readback or offline per-frame waits. Cost is diagnostic; it does not attenuate vectors.

`third_party/manifest.json` records source hashes. CMake rejects changed vendor inputs. Shaders are built from those sources with the Windows SDK compiler; generated bytecode is not checked in. NVIDIA's model DLL is user-provided and is never included or downloaded by this project.
